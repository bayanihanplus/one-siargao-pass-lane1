# SPM-07A — Controlled Rebuild Doctrine

## Status

SPM is moving from passive dashboard UI to traveler engagement architecture.

This is a controlled front-end IA retreat, not a backend reset.

## Core Product Reframe

Siargao Passport Map is not only a map page.

It is the traveler journey engine inside One Siargao Pass.

The target loop is:

1. Choose a journey.
2. See trail families.
3. Open a trail.
4. Understand destinations and stops.
5. Unlock Passport Stamps through verified movement.
6. See achievements and next unlocks.
7. Return and continue.
8. Ask the AI Passport Assistant when confused.

## What We Keep

- Passport Map route.
- Passport Trails route.
- Tri-Island Joiner live route.
- Trail family preview routes.
- QR / stamp / verification language.
- Package progress concept.
- Traveler pass and trip context.
- Backend/governance boundaries.

## What We Stop Doing

- Static instruction blocks as primary UX.
- Hidden trail families.
- Passive placeholder cards without engagement.
- Generic CTAs such as “View all.”
- Compliance-heavy language as the main traveler copy.
- Fake checkout, fake booking, fake QR unlocks, or fake operator readiness.

## Required Engagement Surfaces

1. SPM Journey Hub.
2. Trail Family Launcher.
3. Trail Detail / Journey Page.
4. Passport Stamps + Achievements.
5. Next Unlock / Retention.
6. DIY Trail Builder Preview.
7. Events Discovery Preview.
8. AI Passport Assistant SME.

## AI Passport Assistant Role

The assistant is a subject matter expert for:

- Passport Trails.
- Trail families.
- Destinations and stops.
- QR and Passport Stamp logic.
- Event-linked movement.
- Trip/pass/payment status explanations.
- Live vs preview vs locked states.
- Next traveler actions.

The assistant must not claim:

- booking confirmation,
- payment confirmation,
- guide assignment,
- manifest approval,
- boarding clearance,
- verified stamp completion,

unless backend state proves it.

## Hard Boundaries

No backend or Prisma expansion in this doctrine lane.

No final map overlay.

No checkout/payment/operator/guide/manifest execution.

No fake progress or fake completion.
