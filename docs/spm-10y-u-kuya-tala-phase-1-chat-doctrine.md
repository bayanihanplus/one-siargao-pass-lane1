# SPM-10Y-U — Kuya Tala™ Phase 1 Chat Doctrine

## Status

Phase 1 traveler chat is active.

## Enabled

- Text chat
- Guided OSP/SPM answers
- Deterministic intent handling
- Visible traveler context usage
- Approved knowledge spine usage
- Emergency & Safety guidance
- Official Safety Broadcast explanation

## Not Enabled

- Speech input
- Microphone input
- Open-ended LLM retrieval
- Operator-uploaded KB ingestion
- LGU KB upload from traveler UI
- Booking creation
- Payment mutation
- Pass issuance
- Stamp unlocking
- Emergency dispatch
- Official broadcast sending

## Hard Rule

Kuya Tala™ must be chat-able in Phase 1 because it is the traveler’s direct support interface. But it must remain governed and must not pretend to have infrastructure that does not exist yet.
