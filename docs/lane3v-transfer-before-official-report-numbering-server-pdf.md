- official: false

- generatedAt
- generatedBy
- limits
- summary
- rows
- approvalEvents

### Backend Draft CSV Export

Available endpoint:

- GET /api/v1/osp-qr/reports/manifest-approval/draft.csv

Behavior:

- returns text/csv
- includes DRAFT watermark
- includes report metadata rows
- includes report data rows
- creates ReportExportAudit record
- format: CSV
- official: false
- reportNumber: null

### Draft Print / Save as PDF View

Available endpoint:

- POST /api/v1/osp-qr/reports/manifest-approval/draft-print-audit

Behavior:

- creates ReportExportAudit record
- format: PRINT_VIEW
- official: false
- reportNumber: null
- metadataJson.printMode: BROWSER_PRINT_SAVE_AS_PDF
- frontend redirects back to /lgu?panel=reports&action=print-audit-recorded&print=1
- browser print dialog is triggered after audit record is created

### Export Audit Read Endpoint

Available endpoint:

- GET /api/v1/osp-qr/reports/export-audits

Behavior:

- read-only
- returns latest ReportExportAudit records
- role-governed
- used by LGU Reports / Export panel
