# One Siargao Pass — Lane 1 Repository Scaffold

This repository contains the **Lane 1 only** implementation scaffold for One Siargao Pass:

- auth and roles
- user profiles
- traveler registration and trips
- OSP pass issuance and QR identity
- activities
- booking linkage (including external/pre-OSP support)
- manifest generation and submission
- manifest approval workflow
- basic notifications

Excluded from this lane by design:

- payments
- payouts
- Passport Trails / Siargao Passport Map
- AI assistant
- OTA partner APIs
- accommodation and rentals commercial logic
